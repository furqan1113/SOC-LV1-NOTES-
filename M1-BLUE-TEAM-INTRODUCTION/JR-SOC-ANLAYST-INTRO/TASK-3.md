# Task 3 – Being a Security Analyst

## 1. Main Concept

A Security Analyst works with security tickets/alerts, investigates them, and resolves them within the required time.

## 2. Important Things to Remember

- A ticket represents a security alert or task that needs attention.
- SOC analysts may handle many alerts during a shift.
- Prioritize and investigate alerts efficiently.
- Resolve or escalate alerts according to the situation.
- Continuous learning is necessary because threats and attacks constantly change.

## 3. What I Should Understand / Be Able to Do After This Task

Understand what the daily work of a SOC analyst looks like and be able to navigate an alert dashboard, review security alerts/tickets, and begin investigating them efficiently.

## Practical – Important Things to Remember

- Check and analyze security alerts.
- Identify suspicious information, such as an IP address.
- Use threat intelligence to check whether the IP is malicious.
- If confirmed malicious, escalate to the correct SOC/security person.
- Take action only if you have permission (e.g., block a malicious IP on the firewall).

### Basic SOC Workflow

Alert → Investigate → Verify threat → Escalate → Take/assist with response action.
