# 🛡️ Threat Modelling

**Threat Modelling = Find risks before attackers exploit them**

It's basically asking:

> "What do we have, what can go wrong, and how do we protect it?"

---

## 4 Basic Steps

### 1. Identify Assets 🖥️

What systems/data need protection?

**Example:** payment database, customer information, web server.

### 2. Find Weaknesses 🔎

What vulnerabilities could attackers exploit?

### 3. Plan Protection 🛡️

Decide how to fix/protect those weaknesses.

### 4. Prevent It Happening Again 🔄

Create policies/processes.

**Example:** security training, secure SDLC, patching policies.

---

## Example

```
Web server
   ↓
Find vulnerability
   ↓
Assess the risk
   ↓
Patch/fix it
   ↓
Create process to prevent it again
```

---

## 🔗 How UKC Connects

- The **Unified Kill Chain (UKC)** shows how attackers might attack.
- **Threat modelling** uses that knowledge to ask:

> "Where could they attack us, and how do we protect that part?"

### Frameworks you may hear in threat modelling:

- **STRIDE**
- **DREAD**
- **CVSS**

---

## 🧠 Remember

> **Threat Modelling** = Identify → Find weaknesses → Protect → Prevent recurrence
